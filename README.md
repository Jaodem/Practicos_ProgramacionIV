# Prácticos de Programación IV – Tecnicatura Universitaria en Programación (UTN)

Resolución de los trabajos prácticos de la materia **Programación IV (2026)** en la **Universidad Tecnológica Nacional (UTN)**. Este repositorio está enfocado en el aprendizaje de arquitecturas escalables, desarrollo con Node.js, APIs y tecnologías modernas.

---

## 📚 Contenido de los prácticos

| Nº | Nombre | Tecnologías / Temas principales |
|----|--------|----------------------------------|
| **TP1** | Agenda de Contactos | Node.js, OOP, <br> JSON Persistence, ESM |
| **TP2** | Agenda Web (SPA) | DOM, OOP, Pico.css, <br> ES Modules, Search Filter |
| **TP3** | Directorio Alumnos | React, Vite, CSS Modules, <br> Data Masking, VCF Parser |
| **TP4** | Calculadora de Préstamos | Python, OOP, <br> CLI, Financial Logic |
| **TP5** | Reporte de Productos | Python, Streamlit, <br> Pandas, Matplotlib |
| **TP6** | **E-Commerce Shop** | **FastAPI, Next.js 15, SQLModel, <br> Shadcn UI, Tailwind CSS** |

---

## 🛠️ Tecnologías y Herramientas Generales
- **Lenguajes y Web**: JavaScript (Node.js/Browser), TypeScript, Python 3, React 18+, HTML5, CSS3.
- **Frameworks y Librerías**: Next.js 15, FastAPI, React 18+, SQLModel, Node.js, Streamlit, Pandas, Matplotlib.
- **Build Tools**: Vite, ES Modules.
- **Estilos**: Tailwind CSS, Shadcn UI, CSS3 (Pico.css, Glassmorphism, Responsive Grid).
- **Entorno**: Linux (Fedora/Arch) utilizando el editor **Zed**.
- **Conceptos**: Arquitecturas desacopladas (API REST), Programación Orientada a Objetos (OOP), Hooks, Persistencia de datos, Análisis de Datos y Visualización.
- **Versionado**: Git / GitHub con flujo de commits atómicos.
